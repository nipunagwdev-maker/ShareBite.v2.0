## 🌱 What is ShareBite?

ShareBite is a food-sharing website. Shops, homes and events post their
**surplus food**, and people in the community can **browse, request and
collect it** before it goes to waste.

> A university project for **CMIS 3124 – Web Designing & E-Commerce**.

## 🤖 AI Assistant

Every page has an **AI Assistant** button in the navigation bar. It opens a
chatbot that answers questions about ShareBite, such as how to request food or
how the status tracking works.

![AI Assistant](docs/chatbot.png)

## ✨ Features

- 🍽️ **Browse food**: see all available food, no account needed
- 📝 **Share food**: post surplus food with pickup details
- 🙋 **Request food**: one request per post
- 📍 **Track status**: Available → Requested → Picked Up → Completed (or Expired)
- 🔐 **Login and roles**: provider, user and admin
- 🤖 **AI chatbot**: available on every page

## 🚀 Run it on your computer

```bash
git clone <your-repository-link>
cd sharebite-app
npm install
npm run dev
```

Then open `http://localhost:5173` in your browser.

> 🔑 Supabase keys go in a `.env` file. Never upload this file to GitHub.
